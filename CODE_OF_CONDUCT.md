# Code of Conduct

Participants in Memovi are expected to collaborate in good faith.

## Expected behavior

- Be respectful and constructive.
- Assume good intent; disagree with ideas, not people.
- Do not harass, threaten, or discriminate.
- Do not share others’ private information.
- Keep discussion focused on the project.

## Unacceptable behavior

Harassment, hate speech, sexualized language or imagery, personal attacks,
trolling, and other conduct that would reasonably be considered unwelcome in a
professional setting are not acceptable.

## Enforcement

Project maintainers may remove comments, close issues or pull requests, and
refuse contributions that violate this Code of Conduct.

**Human input required:** no dedicated enforcement email is published. Until
one is added, Code of Conduct concerns should be reported **privately** to the
GitHub repository owner. Do not use public issues for harassment reports.

This document is adapted in spirit from the Contributor Covenant. It does not
claim a specific version adoption or a named enforcement officer.
